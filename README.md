## Projets phares

### [Kabiyè–Èʋɛ NLP Toolkit](https://github.com/cherif-tg/tg_nlp_toolkit)
> Toolkit open-source de traitement automatique des langues togolaises : traduction automatique **français ↔ éwé** à partir d'un modèle NLLB-200 (600M) fine-tuné par LoRA, entraîné sur un corpus parallèle de **65 640 paires** (Bible Éwé 1913 + OPUS NLLB filtré).

**Résultats (test, 6 564 paires) :** FR → Éwé à **BLEU 18,71 / chrF++ 41,83** (+7,3 pts vs zero-shot)

**Technologies :** Python · HuggingFace Transformers · PEFT/LoRA · NLLB-200 · FastAPI · Gradio · SentencePiece

**[ Voir le dépôt](https://github.com/cherif-tg/tg_nlp_toolkit)** | **[ Démo en ligne](https://huggingface.co/spaces/cheriftenga/nllb-ewe-demo)** | **[ Modèle sur HuggingFace](https://huggingface.co/cheriftenga/nllb-200-distilled-600M-ewe-lora)**

### [OpenMind RAG](https://github.com/cherif-tg/openmind)
> Système de **Retrieval-Augmented Generation (RAG)** complet : ingestion multi-format (PDF, CSV, DOCX, Markdown, Web), découpage, vectorisation, recherche sémantique, **re-ranking** et génération de réponses **avec citations des sources**. Livré avec une API FastAPI et une interface Streamlit, avec un LLM hybride (Groq / Ollama / HuggingFace).

**Technologies :** Python · LangChain · ChromaDB · sentence-transformers · Groq · FastAPI · Streamlit

**[ Voir le dépôt](https://github.com/cherif-tg/openmind)**
